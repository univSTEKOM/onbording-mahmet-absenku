# UI/UX & Feature Review

**Tanggal:** Rabu, 22 Juli 2026 – 08:25

Dokumen ini berisi hasil testing dan evaluasi terhadap aplikasi **AbsenKu**. Fokus utama perbaikan adalah **konsistensi UI/UX, kualitas pengalaman pengguna, sinkronisasi data, serta reusability komponen**.

---

# 🎯 Objective

Lakukan redesign dan refactor pada halaman yang disebutkan dengan prinsip berikut:

* Gunakan **design system** yang konsisten di seluruh aplikasi.
* Maksimalkan **reusable components** agar tidak terjadi perbedaan UI antar halaman.
* Tingkatkan **visual hierarchy** sehingga informasi lebih mudah dipahami.
* Tingkatkan **readability** dan **accessibility**.
* Pastikan seluruh data selalu sinkron dengan server.
* Seluruh halaman harus terasa seperti satu produk yang sama (konsisten, modern, premium, dan intuitif).

---

# Admin

## 1. Sinkronisasi Data Profil

### Masalah

Saat melakukan update profil ditemukan beberapa masalah:

* Sebagian data berhasil tersimpan, namun sebagian lainnya tidak.
* Setelah proses penyimpanan berhasil, muncul **double toast notification**.
* Data pada halaman profil tidak langsung diperbarui sehingga UI tidak mencerminkan data terbaru dari server.

### Perbaikan

* Pastikan seluruh field berhasil tersimpan ke server.
* Hilangkan duplicate toast notification.
* Setelah update berhasil:

  * lakukan re-fetch data, atau
  * update cache sehingga data langsung berubah tanpa perlu refresh halaman.
* Seluruh komponen yang menggunakan data profil harus ikut ter-update secara otomatis.

## 2. Halaman Riwayat Kehadiran

### Masalah

UI halaman riwayat kehadiran Admin belum konsisten dengan halaman Riwayat Kehadiran milik Karyawan.

### Perbaikan

Samakan design system dengan halaman Riwayat Kehadiran Karyawan yang terbaru.

Gunakan pola yang sama untuk:

* Filter
* Date Picker
* Search
* Status Badge
* Table/Card Layout
* Empty State
* Loading State

### Filter

Filter harus fleksibel dan reusable.

Mendukung:

* Hari ini (default)
* Tanggal tertentu
* Rentang tanggal
* Status kehadiran
* Nama karyawan
* Department (jika tersedia)

Filter dapat dikombinasikan secara dinamis.

## 2. Face Recognition

### Masalah

Saat ini Face Recognition hanya digunakan saat Check In.

### Perbaikan

Face Recognition harus digunakan pada:

* Check In
* Check Out

Setelah proses verifikasi berhasil:

* foto hasil capture disimpan
* foto dapat dilihat oleh Karyawan
* foto juga dapat dilihat oleh Admin

### Mode Capture

Sediakan dua metode capture:

#### Auto Capture

* kamera mendeteksi wajah
* ketika posisi wajah sudah sesuai
* sistem otomatis mengambil foto

#### Manual Capture

Jika Auto Capture gagal atau terdapat kendala:

* user dapat menekan tombol Capture secara manual.

Gunakan satu komponen Camera Capture yang reusable untuk seluruh proses Face Verification.

## 4. Sidebar

### Masalah

Bagian User Profile pada Sidebar memiliki lebar yang tidak konsisten dibandingkan item menu lainnya.

Hal ini menyebabkan tampilan terlihat janggal.

### Perbaikan

Pastikan komponen User Profile menggunakan:

* width yang sama dengan item sidebar
* padding yang konsisten
* border radius yang konsisten
* hover state yang sama
* active state yang sama

User Profile harus menjadi bagian dari design system Sidebar sehingga seluruh elemen memiliki alignment dan spacing yang seragam.
