### H2. Admin route eforeLoad — redirect catch

**Root Cause:**
6 admin route files pattern:
`	s

  try {
    if ((await fetchRole({})).data?.user?.role !== 'admin') {
      throw redirect({ to: '/dashboard' })
    }
  } catch {
    throw redirect({ to: '/login' })
  }

`
When ole !== 'admin', 	hrow redirect is caught by catch, then user is sent to /login instead of /dashboard.

**Fix Strategy:**
`	s

  try {
    const res = await fetchRole({})
    if (res.data?.user?.role !== 'admin') {
      throw redirect({ to: '/dashboard' })
    }
  } catch (e) {
    if (e instanceof redirect) throw e
    throw redirect({ to: '/login' })
  }
}
`

**Risk:** Very Low. Standard TanStack Router pattern.
